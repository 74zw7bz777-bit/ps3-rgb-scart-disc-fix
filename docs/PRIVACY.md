# Privacy review

The archive is built from an explicit file allowlist, with no Git history, user
profile, conversations, private measurements, system modules or RAM dumps.
Known personal names, home paths, console IP markers and credential markers
were scanned in every allowed file and the decrypted plugin payload; no matches.
Short VSH anchors and fixed AV request templates are compatibility data, not
personal console-memory captures. The SELF is not console-personalized.

ZIP timestamps are fixed; no UID, hostname or owner metadata is included. Tool
source authorship/license notices are retained and do not identify the tester.
Only this reviewed archive/file list is suitable for handoff; do not upload the
entire working directory, generated logs or unrelated project folders.

This is a bounded content audit, not a guarantee of anonymity toward a hosting
service. Account identity, connection logs and future commits require separate
review before publication. A neutral project account and GitHub no-reply commit address are used for publication.
